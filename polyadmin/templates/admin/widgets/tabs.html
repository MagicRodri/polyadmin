{# Container widget: several widgets in one card, one visible at a time -- adapted from Flowbite's admin-dashboard "Statistics this month" card. Mirrors the Go adapter's widgets/tabs.html. Each panel is rendered through the same `{% include widget.template %}` the dashboard uses for a top-level widget. The `{% with %}` scope is what makes that safe to nest: it rebinds `widget_data` for the included template only, so the outer widget's own data is still intact for the next panel (and for a Tabs inside a Tabs). Only panels after the first carry x-cloak: with Alpine still loading -- or not running at all -- the first panel stays visible and the rest stay hidden, so the card degrades to its default tab rather than to everything-at-once or nothing. `active` is compared against a plain loop index, never a label, so nothing dynamic is interpolated into an Alpine expression; labels only ever appear as ordinary (auto-escaped) HTML text. #}
