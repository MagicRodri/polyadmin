{# The example shows "N of M row(s) selected". Selection is client side, so the count is filled in by Alpine from the row checkboxes; with no actions declared there are no checkboxes and it degrades to a plain total. The sentence is translated whole, its plural chosen by M, with {n} left for Alpine to fill in. ngettext yields text rather than a JS literal, so the sentence rides in on data-selected-text for x-text to read, and the server renders the n = 0 sentence so the text is right before Alpine runs. #}
