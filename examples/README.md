# Examples

- [`fastapi/`](fastapi/) — reference FastAPI application exercising the
  full feature set: `User` and `Organization` (a foreign key relation),
  with CRUD, search, filters, a dashboard, authentication/authorization,
  actions, custom pages, inlines, and CSV/XLSX export. Runnable, and
  doubles as an integration test.

The Go implementation ships an equivalent Fiber app against the same
domain shape, in its own repository:
[MagicRodri/go-polyadmin](https://github.com/MagicRodri/go-polyadmin).
