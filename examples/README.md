# Examples

- [`fastapi/`](fastapi/) — reference FastAPI application exercising the
  full feature set: `User`, `Organization` and `Role` with foreign-key
  and many-to-many relations, CRUD, search, filters, a dashboard, a
  real login with two accounts of differing permissions, actions,
  custom pages, inlines, and CSV/XLSX export. Runnable, and doubles as
  an integration test.
